# ML / AI Engineering Resources

Fontes de alta confiança para as aulas da `/teach`. O mapa completo por fase está no [ROADMAP](../ROADMAP.md).

## Knowledge

- [Elements of AI — Universidade de Helsinque (versão em PT)](https://course.elementsofai.com/pt/)
  Curso gratuito sobre o que é IA, sem matemática nem programação; o capítulo 4 cobre machine learning (PT de Portugal: "aprendizagem automática"). Use para: conceitos de ML para quem ainda não programa.
- [Google — Introduction to Machine Learning](https://developers.google.com/machine-learning/intro-to-ml)
  Curso curto do Google com definições claras (modelo, rótulo, treino, previsão) e tipos de ML. Use para: vocabulário de ML em inglês.
- [CS50P — Harvard](https://cs50.harvard.edu/python/)
  Curso introdutório de Python com exercícios corrigidos. Use para: tudo da Fase 1.
- [Pense em Python, 3ª ed. (tradução)](https://rodrigocarlson.github.io/PensePython3ed/)
  Livro introdutório em PT com notebooks no Colab. Use para: explicações em português de fundamentos.
- [Python for Data Analysis, 3E — Wes McKinney](https://wesmckinney.com/book/)
  Livro aberto do criador do pandas. Use para: pandas e NumPy.
- [3Blue1Brown — Linear Algebra / Calculus / Neural Networks](https://www.3blue1brown.com/)
  Intuição visual da matemática. Use para: vetores, matrizes, derivadas, backprop.
- [StatQuest](https://www.youtube.com/@statquest)
  Explicações claras de estatística e algoritmos de ML. Use para: intuição de cada algoritmo.
- [ISLP — Introduction to Statistical Learning with Python](https://www.statlearning.com/)
  Livro de referência de ML clássico, grátis. Use para: fundamentos teóricos da Fase 3.
- [fast.ai — Practical Deep Learning](https://course.fast.ai/)
  Deep learning de cima para baixo, prático. Use para: Fase 4.
- [Dive into Deep Learning](https://d2l.ai/)
  Livro interativo com código PyTorch. Use para: detalhes de arquiteturas.
- [Made With ML](https://madewithml.com/)
  MLOps de produção. Use para: testes, versionamento, CI/CD de ML.
- [Hugging Face — LLM Course](https://huggingface.co/learn/llm-course)
  Transformers e LLMs na prática. Use para: Fase 6.
- [Anthropic — Courses](https://github.com/anthropics/courses)
  API, prompting, evals e tool use. Use para: AI Engineering aplicado.

## Wisdom (Communities)

- [DataTalks.Club Slack](https://datatalks.club/slack.html)
  Comunidade dos Zoomcamps. Use para: dúvidas de MLOps, dados e LLMs.
- [r/learnmachinelearning](https://www.reddit.com/r/learnmachinelearning/)
  Iniciantes em ML. Use para: dúvidas de carreira e de conceito.
- [Python Brasil](https://python.org.br/)
  Comunidade brasileira. Use para: networking e eventos em português.
