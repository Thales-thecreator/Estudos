Regras de bolso

  • Use ML quando a regra é difícil de escrever e há muitos exemplos (chuva, spam, sentimento de frases).
  • Não use ML quando a regra é simples e conhecida (tabela de imposto): escreva a regra.
  • O modelo só sabe o que os exemplos mostraram. Exemplos com buraco geram um modelo com buraco.
  • Modelo pré-treinado = alguém já fez o treino; você só pede previsões (M0.7).
