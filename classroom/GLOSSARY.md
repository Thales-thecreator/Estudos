# Glossário de ML

Vocabulário que o Thales já usa corretamente. Termos entram aqui só depois de usados com as próprias palavras.

## Termos

**Modelo**:
O conjunto de regras descoberto no treino, que faz previsões para casos novos.
_Avoid_: algoritmo (é outra coisa), "a IA"

**Treino**:
O processo de descobrir o padrão a partir de exemplos com rótulo; o resultado é o modelo.
_Avoid_: ensinar, programar

**Previsão**:
A resposta do modelo para um caso novo, que ele nunca viu.
_Avoid_: resultado, chute
