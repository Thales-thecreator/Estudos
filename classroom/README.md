# 🎓 Sala de aula

Espaço da skill [`/teach`](../.claude/skills/teach/SKILL.md): aulas curtas e interativas geradas pelo Claude, apoiadas nos materiais do roadmap.

**Como usar:** abra o Claude Code neste repositório e rode, por exemplo:

```
/teach Loops em Python — travei no Problem Set 2 do CS50P
```

| Arquivo / pasta | O que é |
|---|---|
| [`MISSION.md`](./MISSION.md) | Por que você está estudando — guia todas as aulas |
| [`RESOURCES.md`](./RESOURCES.md) | Fontes confiáveis que as aulas usam |
| `lessons/` | Aulas em HTML (abra no navegador) — +10 XP cada, com quiz feito |
| `reference/` | Folhas de consulta rápida |
| `learning-records/` | O que você comprovadamente aprendeu (guia a próxima aula) |
| `GLOSSARY.md` | Vocabulário técnico que você já domina |
| `NOTES.md` | Suas preferências de ensino |

As pastas e arquivos opcionais são criados pela própria `/teach` conforme forem necessários.
